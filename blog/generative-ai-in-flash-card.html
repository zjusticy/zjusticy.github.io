Add Gemini AI to a flash card project using Serverless function

20 Spt, 2024

For the previous flash card project, please check a-flash-cards-project

Generative AI is a type of artificial intelligence technology that can produce various types of content, including text, imagery and audio.

Here we integrated Google's Gemini pro API into our existing flash card project. For more information about Gemini AI, please check here

Also we use serverless function from Vercel as a gateway to the Gemini API.

  • Note: I use edge rumtime

First, create a api folder in root location and add a generate-content.js file which will be your api name.

// generate-content.js

import { GoogleGenerativeAI } from '@google/generative-ai';

export const config = {
  runtime: 'edge', // Specifies the Edge runtime
};

const genAI = new GoogleGenerativeAI(process.env.API_KEY);

export default async function handler(req) {
  // Handle preflight request

  if (req.method === 'OPTIONS') {
    return new Response(null);
  }

  if (req.method !== 'POST') {
    return new Response('Method Not Allowed', {
      status: 405,

      headers: { Allow: 'POST' },
    });
  }

  const { prompt } = await req.json();

  const encoder = new TextEncoder();

  const model = genAI.getGenerativeModel({ model: 'gemini-1.5-flash' });

  const stream = new ReadableStream({
    async start(controller) {
      try {
        const result = await model.generateContentStream(prompt);

        for await (const chunk of result.stream) {
          const chunkText = chunk.text();

          controller.enqueue(
            encoder.encode(`data: ${JSON.stringify({ text: chunkText })}\n\n`)
          );
        }
      } catch (err) {
        console.error(err);

        controller.enqueue(
          encoder.encode(
            `data: ${JSON.stringify({ error: 'An error occurred' })}\n\n`
          )
        );
      }

      controller.enqueue(
        encoder.encode(`data: ${JSON.stringify({ done: true })}\n\n`)
      );

      controller.close();
    },
  });

  return new Response(stream, {
    headers: {
      'Content-Type': 'text/event-stream',

      'Cache-Control': 'no-cache',

      Connection: 'keep-alive',
    },
  });
}

Add your key to environment param in Vercel API_KEY: your key. Then deploy.

We use stream mode of Gemini API. A streamed response sends bits of data as the model creates it. This way, you can quickly show progress and make the experience more interactive for users. Then we use Server-Sent Events (SSE) at the frontend to seamlessly receive streamed data.

As you can see from above, after you entered a question and an extra prompt on the left side, you can click the AI button to automatically generate the answer on the back of the card by calling the API.

For more information about the params of Gemini API, you can get more information on their dev page
